# FFS Bag CAD & 3D Simulator (v2)

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами на базе параметров технологических карт (ТК), рабочих листов (РЛ) и производственных макетов для линий POLYTEX.

## Возможности

* **Интерактивный 2D-чертёж развёртки полотна (`B × A`)**:
  * Единый масштаб по осям `X` и `Y`, отображение всех сегментов (`T1`, `B3`, `B2`, `B1`, `B2`, `B4`, `T2`), центров фальцев, оси лица `B1` и линий сварных швов (`S1'`, `S1`, `S2`, `S3`).
  * **Зеркальный вид 2D (`T1` справа)** — прямое переключение ориентации чертежа под макеты намотки `R2` с полным сохранением интерактива и перетаскивания.
  * **Переключатель `T1 входит в B3`** — поддержка обеих систем задания внешнего клапана (отдельно от `T1` для стандартных мешков с одним швом `S1` и с включением `T1` внутрь `B3` для макетов с каналом клапана `S1–S3`).
  * Прямое редактирование: клик по любой размерной плашке (`A`, `B`, `B1–B4`, `T1`, `T2`, `E1–E5`, `P1–P4`) открывает ввод значения, а границы сегментов, полосы тиснения/перфорации, швы, разрезы и фотометка перетаскиваются мышью.
* **3D-симулятор кинематики сворачивания (Three.js)**:
  * Честная двухэтапная кинематика без растяжения плёнки (`0%` полотно → `50%` 3D-рукав → `100%` сложенный FFS-рукав с M-фальцами `B2/2` внутрь и точным совмещением шва `S1` с `S1'`).
  * Вращение, панорамирование, зум, быстрые ракурсы (`Изометрия`, `Лицо`, `Шов (тыл)`, `Торец сверху`), режим **«Рентген»** и живой индикатор поперечного сечения `X–Z` с точками швов `S1` и `S3`.
* **Инспектор симметрии, коллизий и оснастки**:
  * Три режима проверки: **«Лицо = Тыл (один шов S1)»**, **«Симметрия лица + канал S1–S3»** и **«Не требуется (только коллизии)»**.
  * Два режима автовыравнивания тиснения (**«Авто: У фальцев»** и **«Авто: От E1»**) + симметрия перфорации `P1–P4`.
  * Контроль смыкания тыла (`B3 + B4` против `B1`), запретных зон допуска фальцовки (`±6 мм`), наезда на кромки `T1/T2` и совместимости с оснасткой POLYTEX (`Small` / `Medium`).
* **Готовые пресеты**:
  * **ТК 03343 (1220×780)** — стандартный FFS-рукав (`A1 / R5`, шов `S1`, контроль `Лицо = Тыл`).
  * **РЛ №1 (940×720)** — `A1 / FFS R1`, осциллированная намотка, фотометка `50×15`.
  * **РЛ №2 (770×650)** — `A2 / FFS R2`, `T1` внутри `B3=183`, канал `S1–S3 = 70 мм`, внутренние разрезы `3×6`, симметрия `30/30 мм` на лице и `5/5 мм` в канале.
  * **10401-339 (790×630)** — макет «Основит PC23M Техно 25 кг» (`A2 / R2`, зеркальный вид 2D `T1` справа, `T1` внутри `B3=183`, канал `S1–S3 = 70 мм`, симметрия `30/30 мм` и `5/5 мм`).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `ffs-bag-cad`) или откройте существующий.
2. Загрузите в корень репозитория файлы из архива: `index.html`, `README.md`, `.gitignore`, `.nojekyll`.
3. Включите **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
