# FFS Bag CAD & 3D Simulator

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами на базе параметров технологической карты (ТК) и рабочих листов (РЛ) для линий типа POLYTEX.

## Возможности

* **Интерактивный 2D-чертёж развёртки полотна (`B × A`)**:
  * Единый масштаб по осям `X` и `Y`, отображение всех сегментов (`T1`, `B3`, `B2`, `B1`, `B2`, `B4`, `T2`), центров фальцев и оси лица `B1`.
  * Прямое редактирование размеров: клик по размерной плашке (`A`, `B`, `B1–B4`, `T1`, `T2`, `E1–E5`, `P1–P4`) открывает быстрый ввод числа, а границы сегментов, полосы тиснения/перфорации, швы, разрезы и фотометку можно перетаскивать мышью.
  * Подсветка технологических зон допуска фальцовки (`±6 мм`), зоны подгиба внутренней кромки `T2` под внешний клапан и канала клапана `S1–S3`.
* **3D-симулятор кинематики сворачивания (Three.js)**:
  * Плавная двухэтапная трансформация без растяжения плёнки: `0%` (плоское полотно) → `50%` (объёмный 3D-рукав) → `100%` (сложенный FFS-рукав с M-фальцами `B2/2` внутрь и разведением кромок `T1` наружу / `T2` внутрь по шву `S1`).
  * Вращение, панорамирование, зум, быстрые ракурсы (`Изометрия`, `Лицо`, `Шов (тыл)`, `Торец сверху`), режим **«Рентген»** и живой индикатор поперечного сечения `X–Z`.
* **Технологический контроль и автоматическая проверка**:
  * Баланс ширины полотна `B = T1 + B3 + 2·B2 + B1 + B4 + T2` (авторасчёт или ручной ввод с расчётом невязки).
  * Контроль смыкания тыльной стороны (`B3 + B4` против `B1`), расчёт положения шва `S1 = T1 + 2·B1 + 2·B2` и канала клапана до `S3`.
  * Подбор оснастки POLYTEX (`Small` / `Medium`) с учётом допуска фальцовки `B2`.
  * Отключаемый контроль симметрии тиснения и перфорации (`Лицо = Тыл` по шагу `B1 + B2` и относительно оси `B1`) + два режима автоподбора (`У фальцев` с заданным отступом и `От E1`).
* **Готовые пресеты**:
  * **ТК 03343 (1220×780)** — базовая техкарта (`B1=390, B2=200, B3=195, B4=195, T1=8, T2=32`, тиснение `E1–E4`, схема `A1 / R5`).
  * **РЛ №1 (940×720)** — `B1=350, B2=100, B3=175, B4=175`, фотометка `50×15`, схема `A1 / FFS R1`, осциллированная намотка.
  * **РЛ №2 (770×650)** — асимметричные клапаны `B3=183, B4=132`, канал клапана `S1–S3` (`70 мм`), внутренние разрезы `3×6`, схема `A2 / FFS R2`.

## Запуск и публикация на GitHub Pages

Приложение состоит из одного статического файла `index.html` без сборки и бэкенда.

### Локально
Откройте `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari).

### Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub (например, `ffs-bag-cad`).
2. Загрузите в корень репозитория файлы из архива: `index.html`, `README.md`, `.gitignore`, `.nojekyll`.
3. Перейдите в **Settings → Pages → Build and deployment**.
4. Выберите **Source: Deploy from a branch**, ветку **`main`** и папку **`/ (root)`**, затем нажмите **Save**.
5. Через 1–2 минуты приложение откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
