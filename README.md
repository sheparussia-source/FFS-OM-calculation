# FFS Bag CAD & 3D Simulator (v8 — Modular)

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами (ТК / РЛ / POLYTEX) с наложением реальных оригинал-макетов (ОМ) и контролем поперечных швов.

## Структура проекта

```text
├── index.html          # разметка интерфейса (классические <script>, работает и по file://, и на GitHub Pages)
├── styles.css          # светлая инженерная CAD-тема, адаптивный сплит 50/50, модальные окна
├── js/
│   ├── presets.js      # базовый шаблон, менеджер пользовательских пресетов (localStorage + JSON) и полифилы
│   ├── geometry.js     # развёртка, швы S1–S3, поперечные швы, симметрия, коллизии, POLYTEX, 3D-кинематика
│   ├── artwork.js      # загрузка ОМ (PNG/JPG/WebP), интерактивная рамка обрезки B×A, контроль пропорций
│   ├── canvas2d.js     # 2D-чертёж, наложение ОМ, поперечные зоны, зеркальный вид, Drag & Drop, инлайн-ввод
│   ├── scene3d.js      # 3D-симулятор Three.js с натяжкой ОМ на рукав, раздельными гранями и сечением X–Z
│   ├── three-loader.js # автоподгрузка lib/three.min.js с резервом на cdnjs и jsdelivr
│   └── app.js          # привязка UI, менеджер пресетов, сплиттер и запуск
├── lib/
│   └── README.txt      # инструкция для 100% офлайн-режима Three.js
├── .gitignore
└── .nojekyll
```
