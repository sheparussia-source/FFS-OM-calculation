# FFS Bag CAD & 3D Simulator (v5 — Modular)

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами (ТК / РЛ / POLYTEX).

## Структура проекта

```text
├── index.html          # разметка интерфейса (классические <script>, работает и по file://, и на GitHub Pages)
├── styles.css          # светлая инженерная CAD-тема, адаптивный сплит 50/50 и окно сохранения пресетов
├── js/
│   ├── presets.js      # базовый шаблон, менеджер пользовательских пресетов (localStorage + JSON) и полифилы
│   ├── geometry.js     # развёртка, швы S1–S3, симметрия, коллизии, оснастка POLYTEX, 3D-кинематика
│   ├── canvas2d.js     # 2D-чертёж, зеркальный вид (T1 справа), Drag & Drop, инлайн-ввод
│   ├── scene3d.js      # 3D-симулятор Three.js с раздельными гранями на сгибах и сечением X–Z
│   ├── three-loader.js # автоподгрузка lib/three.min.js с резервом на cdnjs и jsdelivr
│   └── app.js          # привязка UI, менеджер пресетов, сплиттер и запуск
├── lib/
│   └── README.txt      # инструкция для 100% офлайн-режима Three.js
├── .gitignore
└── .nojekyll
```

## Возможности

* **Пользовательские пресеты без жёстко зашитых заказов:**
  * Кнопка **«+ Сохранить»** сохраняет текущую конфигурацию мешка под любым названием (ТК / РЛ / клиент) в `localStorage` браузера; при совпадении имени пресет аккуратно обновляется.
  * Выпадающий список в шапке позволяет быстро переключаться между сохранёнными пресетами или вернуться к чистому базовому шаблону; кнопка **«✕»** удаляет выбранный пресет.
  * **Экспорт / Импорт JSON** (`ffs-bag-presets.json`) позволяет создавать резервные копии базы пресетов и переносить их между рабочими компьютерами.
* **2D CAD-чертёж и 3D-симулятор:**
  * Единый масштаб 2D, зеркальный вид (`T1` справа), переключатель `T1 входит в B3`, инлайн-редактирование размеров и перетаскивание границ, тиснения, перфорации, швов, просечек и фотометки.
  * Последовательная 3D-кинематика без самопересечений и тёмных артефактов на сгибах, режим «Рентген» и живое сечение `X–Z`.
  * Контроль баланса ширины `B`, смыкания тыла (`B3 + B4` и канал `S1–S3`), совместимости с оснасткой POLYTEX и три режима проверки симметрии тиснения.

## Запуск и публикация на GitHub Pages

* **Локально:** распакуйте архив и откройте `index.html` двойным кликом в браузере.
* **GitHub Pages:** загрузите содержимое архива в корень репозитория и включите **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
* **Полный офлайн-режим 3D:** скачайте `three.min.js` (r128) в папку `lib/` (см. `lib/README.txt`).
