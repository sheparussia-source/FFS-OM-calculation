# FFS Bag CAD & 3D Simulator (v4 — Modular)

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами (ТК / РЛ / POLYTEX).

## Структура проекта

```text
├── index.html          # разметка интерфейса (классические <script>, работает и по file://, и на GitHub Pages)
├── styles.css          # светлая инженерная CAD-тема и адаптивный сплит 50/50
├── js/
│   ├── presets.js      # пресеты (ТК 03343, РЛ №1, РЛ №2, 10401-339), состояние и полифилы
│   ├── geometry.js     # развёртка, швы S1–S3, симметрия, коллизии, оснастка POLYTEX, 3D-кинематика
│   ├── canvas2d.js     # 2D-чертёж, зеркальный вид (T1 справа), Drag & Drop, инлайн-ввод
│   ├── scene3d.js      # 3D-симулятор Three.js с раздельными гранями на сгибах и сечением X–Z
│   ├── three-loader.js # автоподгрузка lib/three.min.js с резервом на cdnjs и jsdelivr
│   └── app.js          # привязка UI, перетаскиваемый разделитель и запуск
├── lib/
│   └── README.txt      # инструкция для 100% офлайн-режима Three.js
├── .gitignore
└── .nojekyll
```

## Что исправлено и улучшено в v3

1. **Чёткие 3D-сгибы без тёмных артефактов**: сетка разделена на 7 независимых панелей по 6 линиям сгиба (`computeVertexNormals()` больше не усредняет противоположные грани).
2. **Последовательная 3D-кинематика без самопересечений**: стенки `B2` → внутренний клапан `B4 + T2` → внешний клапан `B3 + T1` снаружи (`-gap`) → закладка M-фальцев `B2/2`. Протестировано с шагом `1%` на всём диапазоне `0–100%` (0 коллизий).
3. **Точный 2D Drag & Drop 1:1**: исправлена опора перетаскивания границ в зеркальном режиме (`T1` справа) и шаг границы правого фальца `B2R`.
4. **Неискажённая 3D-графика «ЛИЦО»**: компенсация соотношения сторон канваса `2048×1024` и масштаб кегля строго по `B1`.
5. **Необрезаемые подписи на 2D**: плашки `E1–E5` и `P1–P4` выведены поверх маски полотна; размерная линия `A` не наезжает на сегменты при ручном `B < Σ`.
6. **Безопасный автоподбор «Авто: От E1»**: предотвращает перекрытие полос `E2/E3` на узких рукавах (`РЛ №2`, `10401-339`) и выводит пояснение в инспекторе.
7. **Автономный загрузчик Three.js и контроль POLYTEX**: очистка статуса при переключении на резервный CDN и выделение предельного диапазона оснастки `Medium (260–289 мм)`.

## Запуск и публикация на GitHub Pages

* **Локально:** распакуйте архив и откройте `index.html` двойным кликом в браузере (сборщик и локальный сервер не требуются).
* **GitHub Pages:** загрузите содержимое архива в корень репозитория и включите **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
* **Полный офлайн-режим 3D:** скачайте `three.min.js` (r128) в папку `lib/` (инструкция в `lib/README.txt`).
