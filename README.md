# FFS Bag CAD & 3D Simulator (v8 — Modular)

Интерактивный 2D CAD-конструктор и 3D-симулятор формирования FFS-мешка с боковыми фальцами (ТК / РЛ / POLYTEX) с наложением реальных оригинал-макетов (ОМ) и контролем поперечных швов.

## Структура проекта

```text
├── index.html          # разметка интерфейса (классические <script>, работает и по file://, и на GitHub Pages)
├── styles.css          # светлая инженерная CAD-тема, адаптивный сплит 50/50, модальные окна
├── js/
│   ├── presets.js      # базовый шаблон, менеджер пользовательских пресетов (localStorage + JSON) и полифилы
│   ├── geometry.js     # развёртка, швы S1–S3, поперечные швы, симметрия, коллизии, POLYTEX, 3D-кинематика
│   ├── artwork.js      # загрузка ОМ (PNG/JPG/WebP), интерактивная рамка обрезки B×A, контроль пропорций
│   ├── canvas2d.js     # 2D-чертёж, наложение ОМ, поперечные зоны, зеркальный вид, Drag & Drop, инлайн-ввод
│   ├── scene3d.js      # 3D-симулятор Three.js с натяжкой ОМ на рукав, раздельными гранями и сечением X–Z
│   ├── three-loader.js # автоподгрузка lib/three.min.js с резервом на cdnjs и jsdelivr
│   └── app.js          # привязка UI, менеджер пресетов, сплиттер и запуск
├── lib/
│   └── README.txt      # инструкция для 100% офлайн-режима Three.js
├── .gitignore
└── .nojekyll
```

## Новое в v7

* **Наложение оригинал-макета (ОМ) на 2D-чертёж и 3D-мешок (вкладка «Макет ОМ» + кнопка «+ Макет ОМ» / перетаскивание файла прямо на 2D-холст):**
  * Поддержка PNG / JPG / WebP с раздельной регулировкой прозрачности для 2D и 3D.
  * Интерактивное окно **«Выделить рамку B×A»** — позволяет обрезать поля и штамп листа ОМ мышью с живым контролем совпадения пропорции `B / A`.
  * Переключатели **«ОМ зеркальный (T1 справа)»** (для макетов под `R2`) и **«Повернуть 180°»** (для `A2`) автоматически синхронизированы с 2D и 3D.
  * В 3D реальная графика натягивается прямо на сворачивающийся рукав — сразу видно, не уходят ли логотипы, штрихкоды и текст на сгибы фальцев, под шов `S1`, под тиснение или в поперечные швы.
* **Поперечные швы и «мёртвые зоны» дизайна (вкладка «Швы и обработка»):**
  * Задание ширины верхнего и нижнего поперечного шва (`Шов верх`, `Шов низ`) и мёртвой зоны отступа от шва (`Мёртв. зона`).
  * Визуализация зон поперечной сварки на 2D и 3D, расчёт рабочей высоты печати `A_эфф`.
  * Автоматическая проверка попадания фотометки, внешних/внутренних разрезов (`C1/D1`, `C2/D2`) и тиснения в клапане (`F/G`) в зону поперечного шва или мёртвую зону.

## Запуск и публикация на GitHub Pages

* **Локально:** распакуйте архив и откройте `index.html` двойным кликом в браузере.
* **GitHub Pages:** загрузите содержимое архива в корень репозитория и включите **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
* **Полный офлайн-режим 3D:** скачайте `three.min.js` (r128) в папку `lib/` (см. `lib/README.txt`).

## Обновление v8

* **Авторасчёт внутреннего клапана `B4` по умолчанию:** параметры вводятся прямо по бланку ТЗ (Форма №19) и ОМ — `A`, `B`, `B1`, `B2`, `B3`, `T1`, `T2` — а `B4` вычисляется автоматически как остаток ширины полотна $B - (T_1 + B_{3,\text{чист}} + 2 B_2 + B_1 + T_2)$.
* Галочки **«Авто»** на полях `B` и `B4` взаимоисключающие: при необходимости можно переключиться на авторасчёт `B` или на полностью ручной ввод обоих полей.
